# PRODIGY_WD_03
Tic-Tac-Toe Web Application

Task 3: Tic-Tac-Toe Web Application
Web Development Internship @ Prodigy InfoTech

📝 Project Overview
This repository contains the code for Task 3 of the Prodigy InfoTech Web Development Internship. The objective was to build an interactive Tic-Tac-Toe web application. To exceed the baseline requirements, this application features a dual-mode system allowing users to play against another human or against an unbeatable AI opponent.

✨ Features
Dual Game Modes: Toggle seamlessly between Player vs. Player (PvP) and Player vs. AI (PvAI).
Unbeatable AI: The PvAI mode utilizes the Minimax algorithm, ensuring the computer always plays the mathematically optimal move.
Dynamic Game State: Real-time tracking of turns, winning conditions, and draw states.
Modern UI/UX: Features a dark glassmorphism design with neon text shadows, pop-in animations, and a fully responsive grid.

🛠️ Technologies Used
HTML5: Structural layout of the game board and control panels.
CSS3: Advanced styling using CSS Grid, backdrop-filters, custom animations, and responsive design.
Vanilla JavaScript: Complex game logic including array manipulation, event handling, and the recursive Minimax algorithm.

🚀 How to Run the Project

Download or clone this repository.

Navigate to the folder containing the files.

Simply double-click the index.html file to open it in your default web browser. No local server is required.
